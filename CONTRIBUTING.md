# Contributing to SiteSphere

First off, thank you for considering contributing to SiteSphere! It's people like you that make SiteSphere such a great tool.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on our issue tracker and include:
- A clear and descriptive title.
- Steps to reproduce the issue.
- The expected behavior and the actual behavior.
- Your environment details (PHP version, OS, browser, etc.).

### Suggesting Enhancements
Enhancement suggestions are welcome! Please include:
- A clear description of the proposed feature.
- Explain why this enhancement would be useful to most users.
- Mockups or screenshots if applicable.

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. Ensure your local environment is set up (see [README.md](README.md) for instructions).
3. If you've added code that should be tested, add tests.
4. Run the test suite: `composer run test`. Ensure all tests pass!
5. Format your code using Laravel Pint: `./vendor/bin/pint`.
6. Make sure your code follows the existing style and conventions.
7. Issue that pull request!

## Development Setup

To get started with development, follow the Quick Start instructions in the [README.md](README.md) or [INSTALL.md](INSTALL.md).

## Code Style

We follow the standard Laravel code style guidelines. Please make sure to run Laravel Pint before submitting your pull request:

```bash
./vendor/bin/pint
```

Thank you for contributing!
